# Flask To-Do List App

A simple To-Do List web application built using **Python, Flask, Flask-SQLAlchemy, SQLite, HTML, and Bootstrap 5**. This project allows users to create, view, update, and delete tasks through a web interface.

## Features

- Add tasks with a title and description
- View all saved tasks
- Update existing tasks
- Delete tasks
- Store tasks in an SQLite database
- Responsive interface using Bootstrap 5
- Use Jinja templates to render dynamic HTML pages

## Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **ORM:** Flask-SQLAlchemy
- **Frontend:** HTML, Bootstrap 5
- **Templating Engine:** Jinja


## This project demonstrates:

- Building a web application with Flask
- Handling GET and POST requests
- Creating database models with Flask-SQLAlchemy
- Performing CRUD operations
- Rendering dynamic pages with Jinja templates
- Integrating Bootstrap into a Flask application
